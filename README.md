你好，屏幕前的你。我已经在完全离线的情况下蒸馏了你。我敢保证，`be-yourself` 是全世界所有模型都能用、也最懂你的 Skill。验收就麻烦你本人了。

## 半小时能打包一套画风

最近刷设计内容，经常看到有人把画风做成 Skill。把自己调过的配色、线条、材质和光线整理成预设，做封面和配图时就能接着用。要做一个系列，这挺省事。愿意把调过的东西拿出来分享，也挺好。

可几张样图能说明这套预设能出什么图，怎么到了发布帖里，就成了「装上它，你也会像我一样做设计」？自媒体再转几轮，从「这套配色挺好用」讲到「普通人也能一键拥有顶级审美」。中间到底多了什么？安装量上去了，就能证明装的人学会判断一张图好在哪儿吗？如果每转发一次，夸的都是作者有多懂设计，使用的人又学到了什么？

比如做一本展览手册，预设可以帮你把几张插画画成一套。翻到作品介绍那页，你也许会发现，那张最漂亮的插画抢了作品的注意力。是把它拿掉，换成作品的一个局部，还是留着跟照片一起看？我更想知道做手册的人怎么想，又试了哪几版。听完，我可能还是会选另一个版本。这也挺好。

现在想看一张像样的图，生成一张就行。难的是有十张都挺好看，你能说出自己为什么偏爱其中一张，或者为什么十张都想放下。可如果每次都照着同一个预设做，又总有人告诉你这就叫好审美，时间久了，你还分得清什么是自己喜欢的，什么只是看惯了的吗？

## 我为什么不做 Skill

半小时够我把一套出图习惯整理成 Skill。真要选接下来几周做什么，我更愿意把时间花在设计工具的基础设施上。让模型能读到设计师正在做的文件，按他的想法试一版，把画面带回来，留下他能接着编辑的东西。不同的人用同一套工具，可以做出完全不同的东西。

拿 DeepSeek Harness（DSH）里的 Blender 插件来说，做产品外壳时，你可以把选中的对象交给模型，试试侧面那条弧线再收一点会怎样，然后从同一个视角出图对照。你也可以试着往反方向改。工具让几种做法都来得及试，弧线最后怎么收，看两版的人自己定。 [DSH × Blender](https://github.com/sixtysevenlf/dsh-blender-plugin)

ComfyUI 接进来也是一样。你已经调好一条做概念图的工作流，想看同一个造型换几种材质和光线会怎样，插件可以换参数跑几轮，把结果拿回来。你看完也许会发现，最初想要的那种光线其实把材质的细节盖住了，于是再试一轮。 [dsh-comfyui](https://github.com/fandc520/dsh-comfyui)

我做 DSH to Figma，想的也是怎么让设计师在熟悉的工具里多试一版。手上有张参考图，可以先搭成可编辑的图层。想换个视觉方向，就在文件里试，再把两版画面拿回来对照。改到一半断了，也得能查清哪些已经写进文件，才好继续做。我愿意花时间把这些操作接好，因为设计师真正用上它的时候，手里往往已经有一份稿，也有自己的主意。 [DSH to Figma](https://github.com/Duoasa/DSH-to-Figma)

## 给设计师留一点「自负」的空间

我不想教设计师怎么设计。做设计的人多少都有一点「自负」，我也有。自己喜欢什么，哪儿还想再改一下，明明有个现成的做法，为什么还是想试试自己的那一版。我说的个人品味，很大一部分就在这些地方。有些坚持试过才知道值得，有些试完了也会改主意。

我做这些工具，是想让设计师少花点时间在重复操作上。省下来的时间，够他把两个方案摆在一起仔细看一遍，把原先说不清的判断做成一版看得见的东西。也许一个搁了很久的想法，终于有空做出来看看了。

比起让工具越来越像某一个人，我更关心，用它的人能不能越来越像自己。
